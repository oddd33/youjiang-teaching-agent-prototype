教学对话智能体 — 主流程（无框）

自上而下单主干：进入教务系统 → 统一认证 → 选择智能体 → 多轮问答（输入 → 回答 → 溯源）→ 用户选择换 / 留 / 退；右侧为规则说明。

PNG 倍率 
flowchart TD
    Start([进入教务系统]) --> SSO[跳转统一认证]
    SSO --> Auth{认证结果}
    Auth -->|失败| SSO
    Auth -->|成功| Pick[选择智能体
教务 / 科研]
    Pick --> Q[用户输入问题]
    Q --> Reply[智能体回答]
    Reply --> Trace[回答溯源]
    Trace --> Choice{换 / 留 / 退}
    Choice -->|留·继续对话| Q
    Choice -->|换·切换智能体| Q
    Choice -->|退| End([退出会话])

    Note["📌 规则说明

1. 登录失败可重试，不结束会话
2. 回答溯源：内部库名(不可跳转) / 外链(可跳转)
3. 切换智能体：保留记录展示，不沿用原问答历史；
　 换库回答，失败则停留原智能体(§4)
4. 仅「退出会话」到达终点"]
